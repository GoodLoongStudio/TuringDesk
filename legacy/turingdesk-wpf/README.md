# TuringDesk Legacy WPF

这是 TuringDesk 第一代 C# / .NET 8 / WPF 实现的冻结归档。

归档基线 commit：`8a43540f6b57223713f93a90517a3487e71f30fa`

## 用途

该目录仅用于：

- 对照旧版本已经实现过的产品行为；
- 迁移可复用资源、配置格式和测试思路；
- 回查历史问题与实现细节；
- 在新 Native 架构开发期间作为参考实现。

## 状态

此目录不再作为新的正式开发主线。除非为了修复归档可读性或完成迁移，不继续向这里增加产品功能。

原有结构保持完整，包括旧 `src/`、`runtime/`、`scripts/`、安装/打包文件及旧 GitHub Actions 工作流。

新的产品需求与正式架构文档位于仓库根目录 `docs/`。
