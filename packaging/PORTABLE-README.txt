TuringDesk v0.1 Portable Developer Preview
==========================================

Target: Windows 11 x64

HOW TO RUN
1. Extract the whole archive to a normal folder.
2. Double-click Start-TuringDesk.cmd.
3. Close the TuringDesk window when finished. The bundled local Runtime is stopped automatically.

SAFETY BOUNDARY
- No installer.
- No administrator privileges requested.
- No Explorer/shell replacement.
- No registry shell changes.
- No driver installation.
- No startup task/service installation.
- Default AI mode is Mock; this package does not contain an API key.
- Deleting this folder removes the portable preview.

WHAT IT CAN DO IN v0.1
- Run the TuringDesk desktop shell.
- Launch Chrome, VS Code and Windows Terminal when available.
- Discover/focus ordinary top-level Windows windows.
- Demonstrate side-by-side window layout.

KNOWN LIMITATIONS
- This is an unsigned developer preview. Windows SmartScreen may show a warning.
- Real DeepSeek Harness/API-key mode is not enabled by the portable launcher yet.
- Interactive behavior still needs validation on a normal Windows 11 desktop session.

If anything behaves unexpectedly, close TuringDesk. Explorer and the normal Windows desktop remain independent in v0.1.
